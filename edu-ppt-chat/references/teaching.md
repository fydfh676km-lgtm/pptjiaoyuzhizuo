# 教学逻辑与事实边界

## 场景适配

根据材料和用户目标识别主场景，并在第一次产品简报中写明。未限定学段、学科或教育类型；以下主线用于决策，不作为用户可见的固定章节名。

- 教材课：锚点 → 理解 → 示例/证据 → 练习 → 迁移。
- 主题班会：情境 → 体验 → 澄清 → 选择 → 行动。
- 心理健康课：安全 → 觉察 → 理解 → 可选练习 → 支持与求助。
- 家长会：真实问题 → 共识 → 策略 → 家校协同。
- 公开课：核心问题 → 探究 → 证据 → 反馈 → 迁移。
- 培训课：问题 → 方法 → 示范 → 演练 → 应用与复盘。

材料出现其他场景时，依据目标、学习者、任务和评价方式形成适配主线，不强行套用最接近的名称。

## 教学完整性

整套内容共同覆盖：

- 可观察的教学目标；
- 必要知识、证据、案例或示范；
- 教师活动与学习者活动；
- 形成性检查或评价要点；
- 练习、应用或迁移；
- 总结与收束。

互动不能只写“提问、讨论、交流”。必须交代教师动作、学习者动作、问题内容、预期表现和评价依据。各页预计时间之和应与批准的教学时长基本一致；不得靠极端语速或无意义活动填充时长。

## 事实、补充与来源

先使用用户材料。内部保留“文件名/材料标识—页码或位置—生成内容”的来源映射，用于覆盖检查和追溯；默认不把技术性引用标记写进面向学生的页面文案。

可以补充通用教学活动、问题设计、解释方式和课堂组织。用户材料之外的事实、数据、案例或引用必须：

1. 与教学目标确有必要关系；
2. 在生成内容中标记为 `补充内容`；
3. 无法确认准确性时标记为 `待核实`；
4. 不得伪装为教材原文、用户要求或已验证事实。

模型推断不得写成来源事实。来源冲突按 `workflow.md` 的材料职责规则处理。

## 语言与表达

默认跟随用户当前对话语言和主要材料语言。外语课程可在教学需要处保留目标语、释义或必要双语，不为形式统一强制全篇双语。

语言应适合批准的受众和教学场景。页面文字简洁可读；逐字稿可以展开解释，但不得改变页纲结论。

## 安全边界

心理健康及其他敏感主题使用非诊断、非污名化、可选择参与的语言。不要求学习者公开个人经历；涉及风险时说明可信任成年人、学校支持、专业支持或紧急求助边界。不得虚构学生数据、效果保证或权威背书。
